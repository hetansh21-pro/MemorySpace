# Contributing to MemorySpace 🧠

Thank you for your interest in contributing to **MemorySpace**!

## How to Contribute
1. **Fork the Repository** on GitHub.
2. **Clone your fork** locally:
   ```bash
   git clone https://github.com/<your-username>/MemorySpace.git
   cd MemorySpace
   ```
3. **Create a branch** for your feature or bug fix:
   ```bash
   git checkout -b feat/my-new-feature
   ```
4. **Make your changes** and test them:
   ```bash
   ./bin/memoryspace status
   ./bin/memoryspace optimize
   ```
5. **Commit and push** to your fork:
   ```bash
   git commit -m "feat: add support for X"
   git push origin feat/my-new-feature
   ```
6. **Open a Pull Request** against `main`.

We welcome contributions for:
- Support for additional Linux distros (Fedora, openSUSE, Arch, Alpine).
- Additional process protection triggers and integrations.
- UI enhancements for the Web Dashboard.
